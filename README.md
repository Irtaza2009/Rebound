# Rebound

You are an egg. Shoot and bounce around while trying to crack the other egg!

A super fun 2-player local multiplayer game built for Haven Islamabad (a 2 day irl in-person game jam).

​You battle 1v1 against your opponent's egg and try to crack it!

**Play at: https://irtaza.itch.io/rebound**
